# 🎴 斗地主宗师 (Fight The Landlord Master)

一款高品质、全功能、具备**深度局外成长体系（Metagame Progression）**的经典斗地主游戏系统。  
零外部重型依赖，完全基于现代化原生 Web 技术与独立 Python 服务构建，开箱即玩。

---

## 🌟 核心系统特性

### 1. 深度局外成长系统 (Metagame Progression)
* 💰 **资源经济体系**：
  * **金币（欢乐豆）**：入场门槛与输赢结算核心货币。
  * **钻石**：高级货币，用于转盘抽奖、解锁稀有装扮、角色升级。
  * **体力**：对局消耗，随时间自动恢复（每5分钟恢复1点）。
  * **破产低保救济**：当金币低于 1,000 时，每日可领取 3 次救济金（每次 3,000 金币），保障玩家顺畅体验。
* 🏆 **七大排位天梯（Ranked Ladder）**：
  * `倔强青铜` -> `秩序白银` -> `荣耀黄金` -> `尊贵铂金` -> `永恒钻石` -> `至尊星耀` -> `绝世雀圣`。
  * 青铜新手段位保护不掉星；拥有连胜暴击加星、升段奖励，并提供【保星卡】抵扣败局星数。
* 👤 **四大专属角色与技能养成**：
  * **经典阿强**：被动【勤劳致富】农民胜局金币加成 +15%~+35%，技能【丰收连连】连胜额外赠币。
  * **霸道黄大富**：被动【富可敌国】地主获胜加成 +20%~+45%，技能【金玉满堂】底牌为对子/大牌底分提升20%。
  * **神算诸葛**：被动【天机神算】打出炸弹额外获赠钻石，技能【借东风】战败金币损失减免25%。
  * **倾城小曼**：被动【闭月羞花】连胜金币收益大幅加成，技能【春回大地】打出春天排位多加1星、金币翻倍！
  * 角色支持金币升级（Lv1~Lv10）与碎片升星突破。
* 🌲 **六维天赋科技树 (Talent System)**：
  1. **【记牌神算】**：升级解锁并强化局内记牌器（从基础余牌到断张高亮、顺子预测、全局透明）。
  2. **【财源滚滚】**：胜利结算金币额外提升 +6% ~ +30%。
  3. **【连胜风暴】**：连胜局赠送高额金币与额外钻石，大幅提高升星概率。
  4. **【逢凶化吉】**：对局惜败时金币扣除减免 -6% ~ -30%。
  5. **【天赐底牌】**：成为地主时，底牌出现大牌/炸弹的概率提升高达 60%。
  6. **【绝地反击】**：手牌剩余 $\le 3$ 张残牌逆转胜出时，触发额外翻倍奖励。
* 📜 **任务、签到与成就里程碑**：
  * **每日任务**：每日签到、完成对局、地主胜出、打出炸弹、达成春天，完成后领取丰厚金币与钻石。
  * **七日签到**：7天轮换好礼，包含海量金币、钻石、保星卡、角色碎片及专属绝版称号【七日雀皇】。
  * **永久成就大典**：首战告捷、炸弹狂人、春意盎然、大富豪、常胜将军、荣登钻石，赠送钻石与稀有称号。
* 🎡 **幸运转盘与装扮商城**：
  * **聚宝转盘**：每日免费/钻石抽奖，赢取金币、钻石、保星卡与角色碎片。
  * **牌桌皮肤**：经典翡翠、赛博霓虹、紫禁朱红、深海星空。
  * **扑克背纹**：经典雅蓝、赤焰火纹、黑金至尊。
  * **出牌特效**：经典爆破、末日核弹、超音速歼击战机。

### 2. 严谨的局内规则引擎与对战玩法
* 🃏 **全牌型支持**：
  * 单张、对子、三张、三带一、三带二、单顺子（$\ge 5$张）、连对（$\ge 3$对）、四带二单、四带两对、飞机不带、飞机带翅膀（单/对）、炸弹（4张同点）、王炸（双王）。
  * 严格的点数比对规则与炸弹翻倍计算。
  * 智能出牌提示算法：一键循环轮换所有能压制上家的合法出牌方案。
* 🧠 **智能 AI 电脑玩家**：
  * 叫分估值、加倍判定。
  * 角色分工配合：地主上家（顶庄位，控大牌封锁）、地主下家（顺牌位，溜小牌冲线）、队友互不压牌策略。
* 🎮 **多种游戏模式与场次**：
  * **新手初级场**（底分100）、**进阶高手场**（底分500）、**大师荣耀场**（底分2000）、**至尊巅峰场**（底分10000）。
  * **不洗牌狂欢场**（聚类发牌，高炸满天飞，刺激翻倍）。
  * **残局解密闯关模式**：收录 6 大经典残局关卡（如“暗度陈仓”、“引蛇出洞”、“天地大逆转”），寻找唯一破解路径！

### 3. 原生音画与视效
* 🎵 **纯原生 Web Audio API 声音合成器**：无需依赖外部 MP3 文件，零 404 缺失风险，完全支持发牌滑动音、出牌拍桌音、低频炸弹重炮爆破音、火箭冲天音、战机掠过呼啸音、胜利号角欢呼与失败低吟。
* 💥 **Canvas 动态粒子系统**：全屏屏幕震颤、炸弹火焰烟尘、王炸核爆粒子、战机喷气横穿、春天落樱花雨、大胜金币喷泉。

## 🚀 运行与启动方式

### 方式一：Python 一键启动（推荐）
在项目目录下打开终端运行：
```powershell
python start_game.py
```
*启动器将自动启动本地 HTTP 服务并在默认浏览器（Edge / Chrome）中打开游戏！*

### 方式二：直接双击运行
无需任何服务端，直接用浏览器双击打开项目根目录下的 `index.html` 即可畅玩！
